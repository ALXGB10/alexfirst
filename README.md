# Astral Bloom Gallery

A self-contained, interactive cosmic gallery built with Vite and React. The experience features a pointer-reactive starfield, a glowing animated portal, scroll-reactive aurora gradients, and selectable dreamscape scene cards.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually <http://localhost:5173>.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `index.html` — Vite entry HTML.
- `src/main.jsx` — React app, starfield canvas, portal, scene controls, and reactive readings.
- `src/styles.css` — Responsive layout, animations, gradients, glass effects, and motion preferences.
