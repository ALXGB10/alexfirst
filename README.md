# Rolex x Jannik Sinner — 3D Launch Concept

Aplicación web estática con una dirección de arte 3D de lujo para un lanzamiento inspirado en Rolex y Jannik Sinner.

> Demo no oficial: no implica patrocinio, aprobación ni colaboración real de Rolex o Jannik Sinner.

## Ejecutar

```bash
npm run start
```

## Validar

```bash
npm run build
```
